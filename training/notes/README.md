# Evidence notes (training/notes)

This folder is the **evidence package** the capstone panel needs. Fill it in as you go — save screenshots here (training curves, confusion matrix, dashboard History page, live spray demo) and update the numbers below.

## Contents

- `EVIDENCE_TEMPLATE.md` — fill in the blanks as training/hardware tests complete.
- Screenshots (PNG/JPG) saved with descriptive names, e.g.
  `training-curves.png`, `confusion-matrix.png`, `live-demo.jpg`.
- `dataset-stats.md` — how many images, positive/background split, sessions used.
- `field-test.md` — latency, live accuracy, spray tests, tuning notes.
